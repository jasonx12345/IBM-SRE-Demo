How to read these estimates MODEL NOTES

Alert duration is not engineer time. We estimate manual work using manual event count × median acknowledge-to-resolve minutes × mean responders (at least one), then annualize by the documented coverage window.

Runbook repeat rate is the modal known action divided by all manual resolutions. Missing runbooks stay in the denominator. Classification thresholds are judgement calls, evaluated in this order: delete → tune → automate → keep human.
